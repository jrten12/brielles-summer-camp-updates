# Brielle's Summer Camp Tycoon

Windows downloads and the in-game update feed for Brielle's Summer Camp Tycoon.

After the initial installation, open **Game updates** inside the game, download the update, then choose **Save & restart to update**. Your six camp saves stay on your computer.

[Latest Windows download](https://github.com/jrten12/brielles-summer-camp-updates/releases/latest)

Source code is maintained in a separate private repository. This repository contains release information and Windows installers only.
